# Protect Sensor (Resource)

`unifi_protect_sensor` manages selected settings of a UniFi Protect sensor that is already adopted in Protect. Adoption stays manual: creating the resource takes over the adopted sensor with the given MAC, and destroying it only removes it from Terraform state, leaving the sensor adopted and configured as it was. Only the settings set in configuration are managed; removing one from configuration stops managing it without changing it. Smoke and carbon monoxide alarm settings are not managed.

## Example Usage

```terraform
resource "unifi_protect_sensor" "closet_motion" {
  mac  = "24:A4:3C:3D:FE:B9"
  name = "Main Closet Motion Sensor"

  motion_enabled     = true
  motion_sensitivity = 60
}

resource "unifi_protect_sensor" "main_floor_smoke" {
  mac  = "D0:21:F9:8B:6A:ED"
  name = "Main Floor Smoke Detector"
}
```

## Schema

### Required

- `mac` (String) The MAC address of the adopted sensor.

### Optional

- `custom_sensitivity_when_armed` (Boolean) Whether `motion_sensitivity_when_armed` applies while the system is armed.
- `motion_enabled` (Boolean) Whether motion detection is enabled.
- `motion_sensitivity` (Number) Motion sensitivity from 0 to 100, used unless the system is armed with `custom_sensitivity_when_armed` enabled.
- `motion_sensitivity_when_armed` (Number) Motion sensitivity from 0 to 100 while the system is armed and `custom_sensitivity_when_armed` is enabled.
- `name` (String) The sensor name.
- `schedule_mode` (String) When detection runs: `always`, or `when_armed`.

### Read-Only

- `id` (String) The Protect ID of the sensor. It changes when the sensor is re-adopted.
- `type` (String) The sensor model, such as `USL-Motion-US`.
